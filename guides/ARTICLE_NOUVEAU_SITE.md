## Guide pour les captures d'écran

### 1. Page d'accueil
- **À capturer** : Vue complète de la homepage
- **Points clés** : Menu de navigation, widget météo, derniers articles, événements à venir
- **Astuce** : Capture en pleine largeur (1920px) pour montrer le design desktop

### 2. Liste des articles du blog
- **À capturer** : Page `/blog/`
- **Points clés** : Grille d'articles avec images, catégories, dates, nombre de vues
- **Astuce** : Scroller un peu pour montrer plusieurs articles

### 3. Calendrier des événements
- **À capturer** : Page `/evenements/calendrier/`
- **Points clés** : Vue calendrier avec événements colorés par type
- **Astuce** : Choisir un mois avec plusieurs événements

### 4. Détail d'un événement
- **À capturer** : Page d'un événement avec inscriptions ouvertes
- **Points clés** : Description, date, lieu, bouton d'inscription, places restantes
- **Astuce** : Choisir un événement attractif (meeting, sortie club)

### 5. Tableau de bord membre
- **À capturer** : Page `/membres/dashboard/` (connecté)
- **Points clés** : Photo de profil, informations personnelles, mes inscriptions
- **Astuce** : Masquer les données personnelles sensibles si besoin

### 6. Page du bureau
- **À capturer** : Page `/membres/bureau/`
- **Points clés** : Photos des membres du bureau, fonctions, présentation
- **Astuce** : Belle mise en page avec les photos alignées

### 7. Version mobile
- **À capturer** : N'importe quelle page en mode mobile (375px de largeur)
- **Points clés** : Menu hamburger, design adaptatif, navigation tactile
- **Astuce** : Utiliser les DevTools Chrome pour simuler un iPhone

### Comment prendre les captures d'écran ?

**Outil recommandé : Chrome DevTools + Extensions**
1. Ouvrir Chrome DevTools (F12)
2. Cliquer sur l'icône "Toggle device toolbar" (Ctrl+Shift+M)
3. Choisir le device ou personnaliser la taille
4. Utiliser l'extension "Full Page Screen Capture" pour captures complètes

**Post-traitement (optionnel)**
- Ajouter une ombre portée pour effet moderne
- Créer un mockup multi-devices (PC + tablette + mobile)
- Outils : Figma, Canva, ou MockuPhone
