# Guide : Créer un Mockup Multi-Devices pour l'Article

## 🎯 Objectif

Créer une image d'en-tête moderne montrant le site AMCD57 sur plusieurs appareils (ordinateur, tablette, smartphone) pour illustrer l'article de présentation du nouveau site.

---

## 📋 Méthode 1 : Smartmockups (Recommandé - Le plus simple)

### Avantages
✅ Gratuit (avec watermark) ou 7$ pour version sans watermark
✅ Interface très simple et intuitive
✅ Résultat professionnel en 5 minutes
✅ Large choix de devices et angles

### Étapes

#### 1. Préparer les captures d'écran

Avant tout, prenez 3 captures d'écran de votre site :

**A. Page d'accueil (pour MacBook/PC)**
```bash
# Option 1 : Utiliser votre navigateur
1. Ouvrir Chrome → http://127.0.0.1:8000/
2. F12 pour DevTools
3. Ctrl+Shift+P → "Capture full size screenshot"
4. Sauvegarder : homepage-desktop.png
```

**B. Blog ou Calendrier (pour iPad)**
```bash
# Dans Chrome DevTools
1. Cliquer sur l'icône "Toggle device toolbar" (Ctrl+Shift+M)
2. Choisir "iPad Pro" (1024 × 1366)
3. Naviguer vers /blog/ ou /evenements/calendrier/
4. Capture → Sauvegarder : blog-tablet.png
```

**C. Détail d'un article ou événement (pour iPhone)**
```bash
# Dans Chrome DevTools
1. Choisir "iPhone 14 Pro" (393 × 852)
2. Naviguer vers un article ou événement
3. Capture → Sauvegarder : article-mobile.png
```

#### 2. Créer le mockup sur Smartmockups

1. **Aller sur** : https://smartmockups.com/
2. **Cliquer sur** "Create mockup" (bouton bleu en haut à droite)
3. **Rechercher** : "multi device" ou "laptop tablet phone"
4. **Choisir un template** parmi ces suggestions :
   - "MacBook Pro, iPad Pro & iPhone on desk" (vue d'ensemble propre)
   - "Workspace with laptop, tablet and phone" (plus contextualisé)
   - "Floating devices" (fond uni, moderne)

5. **Uploader vos captures** :
   - Cliquer sur le premier device (laptop) → Upload → homepage-desktop.png
   - Cliquer sur le deuxième device (tablet) → Upload → blog-tablet.png
   - Cliquer sur le troisième device (phone) → Upload → article-mobile.png

6. **Ajuster** :
   - Les images s'insèrent automatiquement dans les écrans
   - Vous pouvez zoomer/recadrer si nécessaire

7. **Télécharger** :
   - Cliquer sur "Download" en haut à droite
   - Choisir la résolution (recommandé : 1920px)
   - Si version gratuite : il y aura un petit watermark en bas

8. **Renommer** : `mockup-nouveau-site-amcd57.png`

## 📋 Méthode 2 : Canva (100% Gratuit)

### Avantages
✅ Totalement gratuit sans watermark
✅ Nombreux templates et éléments de design
✅ Possibilité d'ajouter du texte, des logos

### Étapes

1. **Aller sur** : https://canva.com/ (créer un compte gratuit si besoin)

2. **Créer un design** :
   - Cliquer sur "Créer un design"
   - Choisir "Bannière blog" ou dimensions personnalisées : 1920 × 1080 px

3. **Rechercher des templates mockup** :
   - Dans la barre de recherche à gauche : "device mockup"
   - Ou "laptop tablet phone mockup"
   - Choisir un template qui vous plaît (gratuit = avec petite couronne sans barré)

4. **Personnaliser** :
   - Cliquer sur chaque écran de device dans le template
   - Remplacer l'image par vos captures d'écran
   - Upload depuis votre ordinateur

5. **Ajouter du texte** (optionnel) :
   - Cliquer sur "Texte" dans le menu gauche
   - Ajouter un titre : "Nouveau site AMCD57"
   - Style : Police moderne (Montserrat, Poppins), couleur #667eea

6. **Ajouter un fond** (optionnel) :
   - "Éléments" → "Arrière-plans"
   - Choisir un dégradé bleu/violet ou un fond uni

7. **Télécharger** :
   - Cliquer sur "Partager" en haut à droite
   - "Télécharger" → Format PNG
   - Qualité : Standard ou Haute (recommandé)

## 📋 Méthode 3 : MockuPhone (Simple mais limité)

### Avantages
✅ Gratuit sans inscription
✅ Très rapide (2 minutes)
❌ Limité à 1 seul device à la fois

### Utilisation

1. **Aller sur** : https://mockuphone.com/
2. **Choisir un device** : iPhone 14 Pro, MacBook Pro, etc.
3. **Upload votre capture** : Glisser-déposer l'image
4. **Télécharger** : Clic droit → Enregistrer l'image

**Note** : Pour un multi-device, vous devrez créer 3 mockups séparés puis les assembler dans un éditeur d'images (Photoshop, GIMP, Canva).

---

## 📋 Méthode 4 : Shotsnapp (Gratuit, sans inscription)

### Avantages
✅ Gratuit sans compte
✅ Export haute qualité
✅ Personnalisation du fond

### Étapes

1. **Aller sur** : https://shotsnapp.com/
2. **Choisir "Multi-device mockup"**
3. **Upload vos 3 captures** dans les slots (laptop, tablet, phone)
4. **Personnaliser** :
   - Changer la couleur de fond (dégradé bleu/violet recommandé)
   - Ajuster l'angle et la disposition
5. **Export** : Télécharger en PNG haute résolution

---

## 📋 Méthode 5 : Photoshop/GIMP (Avancé)

Si vous maîtrisez Photoshop ou GIMP, vous pouvez créer un mockup 100% personnalisé.

### Ressources gratuites pour PSD de mockup :
- **Freepik** : https://www.freepik.com/free-photos-vectors/device-mockup
- **Mockup World** : https://www.mockupworld.co/free/category/multi-device/
- **GraphicBurger** : https://graphicburger.com/mock-ups/

Téléchargez un PSD multi-device, remplacez les "smart objects" par vos captures d'écran.

## 🎨 Recommandations de Design

### Couleurs de fond suggérées
- **Dégradé violet/bleu** (cohérent avec le site) : #667eea → #764ba2
- **Blanc pur** : Minimaliste et propre
- **Dégradé pastel** : #a8edea → #fed6e3
- **Photo floue de terrain** : Mettre une photo d'avions en arrière-plan floutée (Gaussian blur 50%)

### Composition
- **Devices empilés** : Laptop au centre, tablet à gauche, phone à droite
- **Devices en perspective** : Légèrement inclinés pour effet 3D
- **Espace négatif** : Laisser respirer, ne pas surcharger

### Texte (optionnel)
Si vous ajoutez du texte sur le mockup :
- Titre : "Nouveau site AMCD57 - 2025"
- Sous-titre : "Moderne • Responsive • Sécurisé"
- Police : Montserrat Bold ou Poppins
- Couleur : Blanc avec ombre portée OU #667eea

---

## 📐 Dimensions recommandées

Pour l'image d'en-tête d'article Django :
- **Largeur** : 1920px (minimum 1200px)
- **Hauteur** : 1080px (ratio 16:9 idéal)
- **Format** : PNG ou JPG
- **Poids** : < 500 KB (optimiser avec TinyPNG si nécessaire)

---

## ✅ Ma recommandation finale

**Pour un résultat rapide et professionnel** :

1. **Smartmockups** (si budget 7$ OK) → Résultat instantané, très pro
2. **Canva** (si 100% gratuit requis) → Très bon aussi, plus de contrôle créatif

**Mon choix personnel** : **Smartmockups** avec le template "MacBook Pro, iPad Pro & iPhone floating" sur fond dégradé violet/bleu (#667eea → #764ba2).

---

## 🚀 Checklist finale

Avant d'utiliser l'image dans l'article :

- [ ] Les 3 captures d'écran sont nettes et récentes
- [ ] Le mockup montre bien les 3 devices (laptop, tablet, phone)
- [ ] La résolution est suffisante (minimum 1200px de large)
- [ ] Le poids du fichier est raisonnable (< 500 KB)
- [ ] Le fond est cohérent avec les couleurs du site
- [ ] L'image est renommée de façon explicite : `mockup-nouveau-site-amcd57.png`

## 💡 Astuce bonus

Si vous n'avez pas le temps de créer un mockup maintenant, vous pouvez :

**Option temporaire** : Utiliser une capture simple de la homepage en pleine largeur avec un effet d'ombre portée :

```css
/* Effet CSS si vous avez accès à l'éditeur d'image */
box-shadow: 0 20px 60px rgba(0,0,0,0.3);
border-radius: 8px;
```

Vous pourrez toujours remplacer l'image par un vrai mockup plus tard !

## 🎯 Résumé - Guide express 5 minutes

1. **Prendre 3 captures** : Homepage (desktop), Blog (tablet), Article (mobile)
2. **Aller sur Smartmockups.com** ou **Canva.com**
3. **Choisir template "multi device mockup"**
4. **Upload les 3 captures**
5. **Ajuster** et **télécharger**
6. **Uploader dans l'admin Django** comme image de l'article

C'est tout ! Vous aurez une superbe image d'en-tête professionnelle. 🎉
