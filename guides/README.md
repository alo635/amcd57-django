## 💡 Comment utiliser ces guides ?

1. **Consultez le sommaire** ci-dessus pour trouver le guide dont vous avez besoin
2. **Ouvrez le fichier Markdown** directement dans votre éditeur ou sur GitHub
3. **Suivez les instructions étape par étape**
4. **N'hésitez pas à améliorer** ces guides si vous trouvez des imprécisions

## 📝 Conventions

- Tous les guides sont en **français**
- Format **Markdown** pour une lecture facile
- **Code blocks** avec coloration syntaxique
- **Captures d'écran** incluses quand nécessaire
- **Checklist** pour valider les étapes
